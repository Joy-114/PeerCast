PeerCast Desktop

0.2.0-alpha · ALPHA

一位 Host，一位 Viewer。通过 WebRTC 分享屏幕与独立声音，使用 PC1 连接信息手动建立连接。

Windows 桌面版：Electron + 独立 WASAPI Process Loopback 模块。Windows 11 x64 推荐；按应用捕获需要系统 build 20348 或更新。

所有采集由你的明确操作开始。不会录音到磁盘、后台自动开启麦克风或上传云媒体服务器。STUN 仅协助发现地址；配置 TURN 后媒体可经该 TURN 中转。

进程树隔离不等于从混合 System Audio 中拆音频。启用应用捕获时请关闭 System Audio Send，避免把排除的声音再次混入。

未经代码签名的测试安装包可能显示 Windows 发布者警告。真实跨网络、60 FPS 和目标游戏/语音组合仍需按发布清单验收。

本产品包含 Electron / Chromium / Node.js / .NET。第三方许可随安装文件提供。
